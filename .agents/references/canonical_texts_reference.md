# Canonical Texts Reference — Channel Standard

> **Load rule:** Lazy-load this file during Step 3 (script writing) when attributing teachings to specific texts, or during claim evidence verification (Step 3.5) when a sutra reference must be verified. Do not preload on every task.

## 1. Purpose

This reference ensures **accurate attribution** of Buddhist teachings to their canonical sources. When the script quotes or paraphrases a teaching, the agent must verify which textual tradition it belongs to and use the correct attribution language.

## 2. Pali Canon (Tipiṭaka) — Theravada Primary Source

The oldest surviving complete Buddhist canon, preserved in Pali. This is the primary reference for Theravada Buddhism and is generally considered the closest record to the historical Buddha's teachings.

## 6. Attribution Rules — Quick Reference

### Certainty levels for attribution

| Level | Vietnamese wording | When to use |
|---|---|---|
| **Canonical direct** | "Đức Phật dạy trong Kinh [X] (ref)..." | Verified in Pali Canon / specific canonical text |
| **Canonical paraphrase** | "Theo lời dạy trong Kinh [X]..." | Paraphrasing a verified canonical passage |
| **Commentary/interpretation** | "Ngài [Tên] giải thích rằng..." | Attributed to a named commentator/teacher |
| **Tradition-specific** | "Trong truyền thống [X], người ta hiểu rằng..." | One school's interpretation |
| **Popular/folk** | "Theo truyền thống dân gian..." | Not found in canonical texts |
| **Modern reflection** | "Một cách hiểu phổ biến ngày nay là..." | Contemporary interpretation |

### ❌ Never do

- Attribute a quote to "Đức Phật" without verifying which canonical text contains it
- Present a Mahayana teaching as if it were from the Pali Canon
- Quote a commentary as if it were the Buddha's direct words
- Cite an internet meme or social media post as canonical teaching
- Present one tradition's interpretation as universal Buddhist truth

### ✅ Always do

- Include the specific text reference (Sutta name + Nikāya abbreviation + number)
- Distinguish between the historical Buddha's words and later commentary
- Note when a teaching has different interpretations across traditions
- Verify quotes against SuttaCentral.net or AccessToInsight.org before finalizing
