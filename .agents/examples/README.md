# Examples — Buddhist channel reference only

These files are optional practice material and are **not** final-output schemas.
Load them only when an example is genuinely useful; normal production should follow `AGENTS.md`, the step-specific guide, and the actual project's own data.

### 1. `visual_bible_example_buddhist.json`

A schema-valid example for **ĐƯỜNG VỀ TỈNH THỨC** showing:
- mature semi-realistic 3D Buddhist cinematic styling;
- generic/anonymized human identities;
- stable monastery/prop anchors;
- warm contemplative lighting progression;
- anti-childish-cartoon and policy negatives.

Do not copy its characters, monastery, or story into unrelated videos. The real visual bible must be derived from the current `master_script.txt`.

### 2. `veo_prompts_examples.md`

Four one-shot Veo examples demonstrating:
- scene-specific visual fidelity;
- restrained camera movement and human performance;
- physically plausible light/material behavior;
- no internal transition;
- no readable generated typography;
- mature Buddhist visual tone without forcing statues/lotus/temples into every beat.

These are **craft references**, not reusable scene content.
